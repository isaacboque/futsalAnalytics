# futsalAnalytics audit — 2026-10

Branch `audit/2026-10`, from `main`. Scope: hygiene and credibility only. **No pipeline behaviour changed**, nothing pushed.

## Role of this repo
`futsalAnalytics` is the **public, closed thesis baseline** (bachelor's thesis "Breaking the Data Deadlock", closed 2026-09-05). It is the lineage root of two other repos:
- **IAFS** (local folder; its `origin` is this repo) — the same code on the `training` branch plus a `pivotiq` scaffold; frozen archive.
- **pivotiq** — separate GitHub repo whose `main` is identical to this repo's `main`; its `training` branch is the active scaffold of the successor.
The active rebuild for broadcast footage is `futsal-setpieces` (private). This README already says so, without naming private details.

## Done
1. **CLAUDE.md** committed (was untracked) and corrected: it claimed a `src/pivotiq/` skeleton exists in this repo; it does not (that is IAFS/pivotiq).
2. **README claims vs code** (wording only):
   - `BallTracker` was documented as a 1D/2D Kalman filter with state, noise constants and 5-frame prediction. The code is a rolling mean of the last 5 positions that resets on a gap or a
     jump > 100 px and does not predict. README now describes what the code does and says the earlier Kalman design is not in this repository. (No `Kalman` string exists anywhere in `src/` or `futsal_analyzer_v2.py`.)
   - Module map said calibration is a "Tkinter UI"; it is an OpenCV window.
   - KPI anomaly filter said "step distance > 10 m" / "speed cap 12 m/s"; the code drops a step when **speed ≥ 10 m/s**.
   - Project structure now lists `futsal_analyzer_v2.py`, `LICENSE` and the `.docx` thesis files.
   - Tests section gets venv + `pytest` instructions.
3. **pytest runnable anywhere**: `[tool.pytest.ini_options]` (`testpaths`, `pythonpath = ["src"]`); `ruff` added to the `dev` extra. CI (`tests.yml`: ruff + pytest on ubuntu/windows × py3.10–3.12) already existed and is unchanged.
4. **Generated outputs**: `out/` and `out_smoke/` were already in `.gitignore` but 3 files were tracked (`out/cal.npy`, `out/positions.jsonl` ≈ 2 MB, `out_smoke/positions.jsonl`). `git rm --cached` (files stay on disk).
5. **Security hygiene** (read-only): no assignments of long literal values to key/secret/token/password names in current files or in history (Word/images not searched). No mention of any other project or employer in code/docs.
6. **LICENSE**: README already states MIT, so a standard MIT `LICENSE` file was added (copyright holder as in `pyproject.toml`, year 2026 from the first commit). README now links it.
